## 四、 云服务器生产部署规格与运行环境

| 运行环境指标 | 实际生产配置参数 | 说明与优势 |
| :--- | :--- | :--- |
| **云服务提供商** | 阿里云 (Alibaba Cloud) 华北地域 ECS | 具备高可靠 BGP 多线网络与 DDoS 基础防护 |
| **服务器硬件规格** | **2 核 CPU (vCPU)、1GB 内存 (RAM)、30GB ESSD 磁盘** | 极限低配轻量级规格，验证架构的极低资源开销 |
| **宿主操作系统** | Linux 5.10.134 (Alibaba Cloud Linux 3 / CentOS 兼容) | 生产级稳定内核 |
| **容器运行时** | Docker 26.0.0 + Docker Compose v2 | 全栈容器化解耦隔离，开箱即用 |
| **网络代理网关** | Nginx 1.31.7 Alpine (对外监听标准 Port 80) | 静态资源高效缓存、Gzip 传输压缩、反向代理 |
| **后端运行时** | Python 3.11-slim + Uvicorn + FastAPI 异步驱动 | 异步事件循环驱动，内存常驻仅约 170MB |
| **数据持久化** | SQLite 3.45 (配置 WAL 预写日志模式，Docker 卷挂载) | 零额外内存开销，单文件快照备份，支持并发安全读写 |
| **整体资源占用** | **全栈容器总内存常驻仅 $\approx 180\text{MB}$** | 在 1GB 内存服务器上平稳运行，系统资源富余 80% 以上 |
