## 二、 系统登录与身份认证

### 2.1 登录操作
1. 打开浏览器，输入公网访问地址：`http://39.96.0.20/`；
2. 系统自动加载现代化登录面板：
   - 输入用户名（如 `admin` 或 `reader1`）；
   - 输入密码（如 `admin123` 或 `reader123`）；
   - 点击 **【立即登录】** 按钮；
3. 登录成功后，系统自动缓存 JWT 凭据并跳转至主工作台。

![系统登录界面](../screenshots/login.png)

### 2.2 读者自主注册
1. 在登录卡片下方点击 **【还没有账号？立即注册】**；
2. 填写注册表单：
   - **用户名**：3-30 位字符，用于登录凭据；
   - **真实姓名**：如“张同学”；
   - **电子邮箱**：如 `reader@example.com`；
   - **登录密码**：设置 6 位以上安全密码；
3. 点击 **【完成注册并登录】**，系统自动为新读者生成专属借书卡号（`CARD-2026-XXXX`）。

## 三、 读者端操作指引 (Reader Portal)

### 3.1 书目检索与详情查看
1. 点击左侧主导航栏 **【图书大厅】**（或 **【图书列表】**）；
2. **多维度条件检索**：
   - 在搜索框中输入书名、作者或 ISBN（例如输入“Python”或“算法”）；
   - 选择左侧分类下拉列表（如“计算机科学”、“文学经典”）；
   - 勾选 **【仅显示在架有书】** 复选框，快速过滤已被借空的图书；
3. **查看图书详情**：
   - 列表以卡片/表格清晰列出：图书封面、书名、作者、出版社、分类标签、物理架位（如 `2F-A-01`）；
   - 重点关注 **【在架余量 / 总藏书量】**（例如：`3 / 5 本` 表示馆藏 5 本，当前书架尚存 3 本可借）。

![图书检索与大厅列表](../screenshots/books.png)

### 3.2 发起在线图书借阅
1. 在目标图书条目右侧，点击绿色 **【借阅】** 按钮；
2. 系统弹出借阅确认对话框，展示图书详情、借阅周期（默认 30 天）及应还日期预估；
3. 点击 **【确认借阅】**：
   - 后端在数据库事务中原子校验当前库存与借阅准入条件；
   - 借阅成功后弹出成功提示，图书在架可借册数立即扣减 1；
   - 若当前图书在架为 0，系统会提示“该图书库存不足”并阻止操作；
   - 若读者在借图书已达 5 本上限，系统会弹出额度超限提示。

### 3.3 我的借阅中心与在线续借
1. 点击左侧导航栏 **【我的借阅】**；
2. 页面直观呈现当前读者借出或历史归还的所有记录卡片，包含：
   - **图书信息**：书名、作者、借书卡号；
   - **时间周期**：借出时间、应还截止日期、实际归还时间；
   - **单据状态徽章**：绿色 `借阅中`、灰色 `已归还`、红色 `已逾期`；
3. **办理图书续借**：
   - 在处于“借阅中”且未逾期的图书卡片上，点击 **【申请续借】** 按钮；
   - 系统在原应还日期基础上自动顺延 30 天，并将单据标记为“已续借（1/1）”；
   - 每本图书仅限续借一次，续借后该按钮自动置灰。

### 3.4 图书归还操作
1. 读者在 **【我的借阅】** 列表中找到需要归还的书籍；
2. 点击 **【确认还书】** 按钮；
3. 系统核销单据状态为 `已归还`，记录实际归还时间，图书在架余量自动回补 1 本。

## 四、 管理员端操作指引 (Librarian & Admin Portal)

以 `admin` 账号登录后，系统解锁全部高级运营与管理功能。

### 4.1 运营数据监控大屏 (Dashboard)
1. 登录后默认进入 **【系统大屏】**（Dashboard）；
2. **核心业务指标看板**：
   - 馆藏图书总种数（Titles）
   - 馆藏总册数（Total Volumes）
   - 当前在借图书总数（Borrowed Copies）
   - 全站注册读者总人数（Readers）
3. **轻量级动态图表**：
   - **近 7 天借还走势图**：自研原生响应式 SVG 折线图，悬停可直观查看每日借出量与归还量；
   - **图书分类占比分布**：环形动态分布图，实时展示计算机、文学、自然科学等各类藏书比例；
   - **借阅热门榜 Top 10**：动态高频借阅书目排行榜。

![数据分析大屏与运营看板](../screenshots/dashboard.png)

### 4.2 图书采编入库与书目管理
1. 点击左侧导航 **【图书管理】**；
2. **新书录入**：
   - 点击顶部 **【+ 新增图书入库】** 按钮打开采编弹窗；
   - 录入 ISBN-13 标准书号、书名、作者、出版社、分类归属、出版年份；
   - 标注馆藏物理架位（如 `3F-C-08`）与入库总册数（如 `10`）；
   - 点击保存，新书即刻上架；
3. **书目修改与复本追加**：
   - 点击对应图书的 **【编辑】** 按钮，可修改作者、架位号等信息；
   - 当图书馆追加采购新复本时，调增总册数与在架册数即可；
4. **安全下架校验**：
   - 点击图书的 **【下架】** 按钮；
   - 系统自动核查在借记录：若该书尚有读者未还（`available_copies < total_copies`），系统将强制拦截下架操作，保护馆藏资产完整。

### 4.3 图书分类管理
1. 点击左侧导航 **【分类管理】**；
2. 查看当前全部分类编码、名称与关联图书数量；
3. 支持新增分类（如“人工智能”、“经济管理”）及编辑分类描述；
4. 拥有关联保护机制：若某分类下已有图书，禁止直接删除分类。

### 4.4 全馆借还流转大厅与逾期监控
1. 点击左侧导航 **【借还管理】**；
2. 页面统一呈现全馆读者的所有借还流水单据；
3. **快速筛选流转**：
   - 支持按单据状态过滤：`全部` / `在借中` / `已归还` / `超期违约`；
   - 支持按读者借书卡号、姓名、图书名称进行精准交叉查询；
4. **柜台人工代还**：
   - 读者线下归还图书至柜台时，管理员在流水列表中找到对应单据，点击 **【代还验收】**，即时核销并回补库存；
5. **逾期监控与催还**：
   - 筛选处于红色 `已逾期` 状态的单据，系统清晰标注逾期天数与累计违约金，便于管理员开展针对性联系与催还。

![全馆借阅流转监控大厅](../screenshots/borrows.png)

### 4.5 用户与借书卡管理 (Admin 专属)
1. 点击左侧导航 **【用户管理】**；
2. 分页浏览全站所有读者与管理员账户档案；
3. **角色分配**：可将优秀馆员账号提升为 `管理员 (admin)` 或调整为 `图书运营员 (librarian)`；
4. **账号风控冻结**：
   - 针对长期违约或违规读者，点击操作列的 **【停用】** 切换开关；
   - 停用后该用户 Token 立即失效且无法再次登录，直到管理员点击 **【启用】** 解封。

## 五、 系统容器化部署与运维说明 (DevOps Guide)

### 5.1 生产环境要求
- **操作系统**：Linux (CentOS 7/8, Alibaba Cloud Linux, Ubuntu 20.04+, Debian 11+)
- **配置规格**：最低仅需 **1 核 CPU、1GB 内存、20GB 磁盘**（针对轻量级服务器深度优化）
- **核心依赖**：Docker Engine 20.10+ 与 Docker Compose v2+

### 5.2 一键部署步骤
在服务器上克隆或解压项目代码后，只需执行以下标准指令：
```bash
# 1. 进入项目根目录
cd library-management-system

# 2. 一键构建并后台启动容器集群
docker-compose up -d --build

# 3. 查看容器运行状态
docker-compose ps

# 4. 查看后端运行日志
docker logs -f library-backend
```

### 5.3 数据库日常备份与迁移
系统数据库采用持久化卷模式挂载，真实文件位于宿主机的 Docker 数据卷或项目目录下的数据卷映射中。
- **冷备份**：执行 `sqlite3 /var/lib/docker/volumes/.../library.db ".backup 'library_backup.db'"` 即可生成无锁快照备份；
- **快速恢复**：将备份文件替换回数据目录并重启容器即可瞬间恢复业务。
